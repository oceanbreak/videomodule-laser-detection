# Laser Dataset Inspector

Интерактивный анализ размеченных пар лазерных отметок на подводных снимках. Порядок кадров берётся из `lasers.csv`. Дата и время в имени файла не используются для определения сетапов, сортировки или интерпретации съёмки.

## Установка и запуск

Клонируйте репозиторий и запустите из его корня с Python 3.11.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
cp config.example.yaml config.local.yaml
```

В Windows PowerShell используйте `py -3.11 -m venv .venv`, `.venv\Scripts\Activate.ps1` и `Copy-Item config.example.yaml config.local.yaml`.

Заполните `config.local.yaml`. Пути могут быть абсолютными или относительными к самому файлу конфигурации, в том числе за пределами репозитория. Для путей Windows в YAML используйте прямые косые черты или одинарные кавычки.

- `data.annotations_csv` содержит `image;x1;y1;x2;y2`. Все четыре координаты должны быть заполнены либо отсутствовать. Пустые поля и `NaN` обозначают отсутствие точки. Допустимые координаты лежат в пределах `0 ≤ x < width` и `0 ≤ y < height`.
- `data.setups_csv` содержит `filename;setup`. Первая граница совпадает с первой строкой разметки. Укажите границы по порядку строк разметки. Граничный кадр входит в новый сетап.
- `data.images_dir` задаёт папку фотографий. Без неё работают обзор, графики и экспорт.
- `image.width` и `image.height` задают размер изображения. В шаблоне указан исходный размер 3072×2048.
- `output.directory` задаёт локальный каталог экспорта.

```bash
jupyter lab
```

Откройте `notebooks/01_dataset_inspection.ipynb` и выполните ячейки. В легенде пространственного графика можно скрыть или показать сразу обе серии точек выбранного сетапа. Просмотр кадра читает выбранную фотографию по нажатию кнопки. Углы измеряются в радианах в координатах изображения. Для нормализованного угла точки упорядочены слева направо, а вертикальная пара — сверху вниз.

## Экспорт и данные

Для сохранения результатов установите `EXPORT = True` в последней ячейке и запустите её. Экспорт создаёт в указанной папке шесть автономных HTML-графиков, общую и посетапную статистику, а также таблицу координат и геометрии. Повторный экспорт обновляет эти файлы.

Храните разметку, фотографии, локальную конфигурацию и результаты на своём компьютере. `.gitignore` защищает только от случайного добавления файлов по типовым путям. Не добавляйте реальные данные через `git add -f` или вручную, в том числе из каталогов с другими именами. Перед коммитом ноутбука очистите выводы ячеек и счётчики выполнения.

## Геометрическая калибровка

Запустите `jupyter lab` из корня проекта и откройте
`notebooks/02_geometry_calibration.ipynb`. Ноутбук использует тот же
`config.local.yaml`, что и обзор датасета. CSV-импорт упорядочивает точки слева
направо и при равных X сверху вниз. Подгонка использует только полные пары.
Просмотр фотографий доступен по запросу.

Для каждого сетапа RANSAC независимо подбирает прямую для каждого лазера.
Каждая гипотеза строится по двум различным точкам. Выбирается гипотеза с
наибольшим числом точек внутри порога, а при равенстве — с меньшей суммой
расстояний этих точек. Ортогональная регрессия уточняет прямую по этой группе.
Остаток равен перпендикулярному расстоянию `|ax + by + c|` в пикселях при
`a² + b² = 1`. Угол между прямыми — наименьший неориентированный угол в градусах.
Остаток пары равен максимуму двух остатков. Коридор `±t` принимает пару, если
обе точки удалены от соответствующих прямых не более чем на `t` пикселей.

### Настройки

Необязательная секция `calibration` в `config.local.yaml` переопределяет значения
из [шаблона](config.example.yaml).

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `ransac_threshold` | 10 px | Порог включения точки в консенсус RANSAC |
| `ransac_trials` | 256 | Число гипотез на прямую |
| `corridor_thresholds` | 5, 10, 20, 30, 50 px | Исследуемые полуширины коридоров |
| `training_sizes` | 10, 20, 30, 50, 100, 200 | Размеры выборок для подгонки |
| `repetitions` | 30 | Повторения для каждого размера и каждой доли загрязнения |
| `contamination_fractions` | 0, 0.05, 0.10, 0.20, 0.30 | Доли подменённых обучающих пар |
| `contamination_training_size` | 50 | Число обучающих пар в эксперименте с загрязнением |
| `random_state` | 42 | Начальное значение генератора случайных чисел |

Оценка **in-sample** использует все размеченные пары сетапа и для построения
прямых, и для расчёта остатков. Оценка **out-of-sample** строит прямые на
случайно выбранных кадрах и измеряет качество на всех оставшихся размеченных
кадрах того же сетапа. Размеры выборок без хотя бы одного удержанного кадра
помечаются как `skipped`. Вырожденные подгонки помечаются как `failed`.
Медиана и интервал P5–P95 между повторениями вычисляются по успешным запускам.
В агрегатах отдельно указано число успешных и неудачных запусков.

Эксперимент с загрязнением заменяет целые обучающие пары случайными пиксельными
координатами, сохраняя порядок точек слева направо. Число замен округляется до
ближайшего целого, половина округляется вверх. В пределах повторения все доли
сравниваются на одном разбиении. Удержанные точки всегда исходные. Исследование
характеризует геометрию разметки. Точность реального детектора и характер его
ошибок потребуют отдельной проверки.

### Экспорт калибровки

Установите `EXPORT = True` в последней ячейке ноутбука. Файлы сохраняются локально
в `results/calibration/` относительно файла конфигурации. Путь можно изменить
параметром `output.calibration_directory`.

- `line_parameters.csv` содержит коэффициенты прямых, угол и статус подгонки.
- `in_sample_summary.csv`, `frame_residuals.csv` и `in_sample_corridors.csv`
  содержат сводку, перпендикулярные остатки для размеченных кадров и покрытие коридоров.
- `sample_size_runs.csv` и `contamination_runs.csv` содержат результаты повторений
  с параметрами моделей, метриками удержанных пар, причинами пропуска или сбоя и seed.
- `sample_size_summary.csv` и `contamination_summary.csv` содержат агрегаты повторений.
- `experiment_config.json` содержит настройки, размеры кадра и исходный seed.
- HTML-файлы содержат автономные Plotly-графики. Номера файлов
  `spatial_setup_*.html` соответствуют порядку сетапов в `line_parameters.csv`.

Результаты экспорта могут содержать имена кадров и координаты. Храните эти файлы
вместе с локальными данными и очищайте выводы ноутбука перед коммитом.
